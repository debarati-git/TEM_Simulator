Beginner rule 01

Same console, different purpose

The console remains visually consistent across modes. Only the controls needed for the current task are highlighted, so learners recognise the real instrument without being overwhelmed.

Beginner rule 02

Action + location + reason

Each step names the physical control and explains the visible consequence: wobble reduces, beam becomes circular, spots sharpen, a selected reflection forms DF contrast, or FFT symmetry improves.

Control fidelity

Manual terminology first

The comparison build introduces MAG1, LOW MAG, SA MAG, SA DIFF, PLA, COND STIG, OBJ STIG, DARK TILT, DIFF FOCUS, SA/OL apertures and specimen tilt terminology used in the supplied manuals.
