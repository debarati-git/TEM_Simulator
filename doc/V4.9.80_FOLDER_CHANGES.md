# Version 4.9.80 — Folder-structured S3 Simulator

Based on the approved v4.9.78 folder package, matching the changes in the v4.9.80 single-HTML candidate.

- How to Use modal starts after a 3-second delay.
- Bright Field wobble minimum occurs at +70 µm (Z UP) or −70 µm (Z DOWN), with a ±250 µm stage limit.
- The Skip Step control counts the current step as completed, carries forward the necessary simulated instrument state, and progresses to the next step.
- The original toolbar Skip Step remains accessible while step-confirmation modals are shown; no Skip button is inserted into those modals.
- The original folder structure, all existing S3 URLs, and all 53 previously retained local image assets are unchanged.

Open index.html to start the simulator. An Internet connection is required for S3-hosted imagery.
