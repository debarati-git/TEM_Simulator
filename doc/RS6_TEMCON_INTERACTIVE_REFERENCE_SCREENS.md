# RS6 — Interactive TEMCON reference screens

Changes applied on top of RS5:

- Navigation layout is normalized to six visible sections after Shutdown was renumbered to Section 6; there is no Section 7 navigation slot.
- Sample selection now enables only **Nanoparticles / Suspension**. Bulk Metallic and Cross-section remain visible but locked/disabled.
- Section 1 Step 4 now opens a reconstructed Windows/TEMCON workstation based on the supplied initial-screen reference. The interface is built with HTML/CSS/SVG, not a screenshot. Learners verify HT READY, EVAC READY, and 80 kV by clicking the highlighted live readouts before confirming.
- Section 2 Step 4 instruction text is now exactly: **Confirm upon hearing 3 click sounds**.
- Section 2 Step 6 now opens the interactive TEMCON workstation and highlights the Specimen Exchange / Vacuum readiness area. Learners must inspect/click EVC Status READY before confirming.
- Section 2 Step 8 now uses an interactive holder-model pull-down in the reconstructed TEMCON top status area. The correct model for the enabled nanoparticle workflow is **EM-21010/21020 : Single Tilt Holder**; other supplied reference holder models are available as distractors.
- The supplied PNG screenshots are used only as visual references and are not embedded as the interactive PC screen.
- Existing RS3 completion/consolidation pauses remain unchanged.
