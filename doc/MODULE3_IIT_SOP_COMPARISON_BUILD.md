# Module 03 — IIT SOP Workflow Comparison Build

This build intentionally preserves the existing Module 02 workflow and adds a separate Module 03 so IIT reviewers can compare the two approaches side by side.

## New navigation

- Module 01 — The Column (unchanged)
- Module 02 — The Microscope (existing workflow retained)
- Module 03 — IIT SOP Workflow (new comparison build)

## Module 03 structure

1. Common Setup & Alignment
2. Bright Field Imaging
3. Dark Field Imaging
4. Selected Area Electron Diffraction (SAED)
5. High-Resolution TEM (HRTEM)
6. End Session / Specimen Unload

Each imaging mode is separately selectable for reviewer access. The intended novice learning sequence is Common Setup → Bright Field → DF / SAED / HRTEM → End Session.

## Manual-aligned terminology introduced

The comparison build introduces or foregrounds JEM-2100 terms used in the supplied IIT manuals, including:

- MAG1, LOW MAG, SA MAG and SA DIFF
- MAG/CAM L
- DIFF FOCUS
- STD FOCUS and IMAGE WOBB X
- SHIFT, PLA, COND STIG, OBJ STIG, DARK TILT and BRIGHT TILT
- CL, OL and SA aperture selection and X/Y centring
- specimen Z and alpha/beta tilt
- goniometer GREEN readiness, PUMP/AIR and staged holder positions

## Beginner-learning behaviour

- Current action is highlighted rather than exposing the learner to all controls at once.
- Every instruction includes a short "Why" explanation.
- Bright Field is treated as the baseline aligned condition.
- Dark Field begins from a selected diffracted reflection.
- SAED separates SA-aperture positioning from PLA pattern centring and DIFF FOCUS.
- HRTEM requires objective-aperture removal, Kikuchi-guided zone-axis alignment, OBJ STIG and live FFT.
- The visual screen changes between image, diffraction, DF and HRTEM states.

## Scope of this comparison build

This is a functional structure-and-interaction build intended for IIT review. It is isolated from Module 02 so professor feedback can be collected before deciding which architecture should become the main learner workflow.
