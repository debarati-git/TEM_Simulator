# TEM Simulator v4.9.73 — S3 URL Integration

Approved base: v4.9.72. This is an S3-enabled candidate, not a replacement for the approved baseline until confirmed.

- Substitutes the 53 active image paths with the 53 HTTPS URLs from the user's completed mapping workbook.
- Adds CORS-aware loading for images drawn onto the live phosphor canvas and iTEM camera canvas.
- Preloads only actively used Bright Field specimen images, avoiding three obsolete unused frames.
- Does not change guided step order, microscope controls, timers or simulation completion thresholds.
- Deployment ZIP omits the 53 S3-hosted image copies to reduce distribution size. The full backup ZIP retains all existing images.
- Embedded PNG/SVG data in source code stays embedded and unchanged.

IMPORTANT: Amazon S3 or CloudFront must deliver CORS headers that allow the page origin (or * for public content) for the images painted into HTML canvases; otherwise, the canvas image acquisition/export may fail.
IMPORTANT: Two different source images (section3-l1-modal-reference.png and section3-high-voltage-control.png) were mapped to the same URL in the uploaded workbook. The user-provided URL has been applied to both; confirm the L1 URL is correct.
