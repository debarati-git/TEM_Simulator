# Version 4.9.65 · Help, TEMCON Step 1, and R1 magnification

Based on user-approved working candidate v4.9.64 (itself based directly on v4.9.62).

1. How-to-use quick start now opens once per browser tab session after 1.3 seconds; no repeat when moving from landing page to the guided session. Manual reopening is always possible.
2. Single `?` help icon located beside READY in the shared top navigation, replacing the two longer help buttons.
3. Section 3 Step 1 shows the requested HT verification alert, which must be confirmed before interaction; on acknowledgment the TEMCON PC drawer scrolls automatically to bring the Auto HT target selector into view.
4. Auto HT Target, Step and Time/Step dropdowns are all available in Sections 3 Steps 1–3 and the Time to finish estimate recalculates on each selection. Existing guided progression continues to validate 200 kV, 0.5 kV, 10 sec respectively; Step 4 starts HT ramp.
5. R1 MAG/CAM L readout and initial magnification default to X200 (200×). The existing 1000× through 100000× choices remain available.

The v4.9.64 four visible sections, optional Skip Step, and prior functionality remain unchanged.
